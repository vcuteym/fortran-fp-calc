# fortran-fp-calc

[CI Badge Placeholder]

Simple floating point calculator written in Fortran with pFUnit tests.

## Quick Start

```bash
make
./calc
```

Run tests (requires pFUnit):

```bash
export PFUNIT=$HOME/pfunit  # adjust if pFUnit is installed elsewhere
make check
```
